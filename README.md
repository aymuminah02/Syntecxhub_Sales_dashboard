Welcome to my Data Analytics Portfolio! This repository showcases real-world data analysis projects built using Power BI, focusing on transforming raw data into meaningful insights and interactive dashboards.
1. **Syntecxhub Sales Dashboard**
An end-to-end sales analytics solution designed to monitor business performance and uncover actionable insights.
Objective: Identify high-performing products and top sales regions
Tools Used: Power BI, CSV Data Processing
Key Insights:
Revenue trends over time
Monthly and yearly growth analysis
Regional sales performance comparison
2. **Student Performance Dashboard**
A data-driven project focused on understanding the key factors influencing student success.
Objective: Analyze the impact of attendance and other factors on student performance
Tools Used: Power BI Desktop
Key Insights:
Student grade distribution
Attendance vs performance correlation
Performance benchmarking across groups
**How to Use**
Download the .pbix files from this repository
Open using Power BI Desktop
Use the interactive filters and visuals to explore insights
